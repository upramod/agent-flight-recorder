Of 77 attempts, 60 loaded environments differ from literal scalar substitution, 13 match, and four raise ParserError before any target request. Differences include newline folding and derived file sizes. Every one of the 84 initial fixed trials also differs; all 120 clean environments match. Exact audit counts are in results/v3-loader-fidelity-audit.json.

The corrected loader parses the trusted environment template first, validates injection vector identifiers, substitutes only string values (not mapping keys), and applies the same environment model validation. Injection strings are not interpreted as YAML and replacement is not recursive. The supplied environment goes through the unchanged task initialization and utility/security scorers. Pre-call configuration records environmentLoader=parsed-scalars-v1. The original loader remains available to reproduce historical runs.
